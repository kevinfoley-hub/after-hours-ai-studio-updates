# After Hours AI Mega Studio Updates

This repository hosts update metadata for **After Hours AI Mega Studio**.

## Current version

- Version: **16.0.0**
- Edition: **Book Factory**

## Updater file

`update_manifest.json` is the stable manifest used by the desktop app to check for newer versions.

When a future EXE is published, the manifest should be updated with:

- `version`
- public HTTPS `url`
- `sha256`
- release `notes`

The app should verify the SHA-256 before applying an update.
